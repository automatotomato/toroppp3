## Required Configuration Changes

### 1. Update Site URL in Supabase Auth Settings

**Navigation:**
1. Go to your Supabase Dashboard: https://supabase.com/dashboard/project/mblzyrzsgzccjkwmundc
2. Navigate to: Authentication > URL Configuration

### 2. Configure Edge Function Secrets

**Navigation:**
1. Go to: Project Settings > Edge Functions > Secrets

**Required Secrets:**
- `SITE_URL` = `https://www.3-peakavanza.com`
- `RESEND_API_KEY` = `re_Y5DtsUdn_5Hvv5LyiRjXsPw1Qr3cyesiA`

Note: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, and `SUPABASE_SERVICE_ROLE_KEY` should already be auto-populated.

### 3. Verify Configuration

After making these changes:

1. Test the password reset flow:
   - Go to: https://www.3-peakavanza.com/forgot-password
   - Enter a user email
   - Check that the reset link points to `www.3-peakavanza.com`

2. Verify edge function has access to secrets:
   - The `send-password-reset` edge function should successfully use both RESEND_API_KEY and SITE_URL

## Expected Behavior After Configuration

When users request a password reset:
1. They visit: `https://www.3-peakavanza.com/forgot-password`
2. Enter their email address
3. Receive an email with a reset link pointing to: `https://www.3-peakavanza.com/reset-password?token=...`
4. Click the link and land on the correct domain
5. Set their new password
6. Get redirected to the dashboard

## Technical Details

- The edge function `send-password-reset` (line 62) reads: `Deno.env.get('SITE_URL') || 'https://www.3-peakavanza.com'`
- Supabase's `admin.generateLink()` uses the Site URL from auth configuration
- The action_link generated by Supabase includes the full URL with auth tokens
- This URL must point to the production domain, not the Bolt.host development domain
